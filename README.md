# Student Attendance Tracker

## Project Description

Student Attendance Tracker is a web-based attendance
management system developed for college students.

This project helps to record and manage student attendance
department-wise.

## Features

- Add student name and roll number
- Select department
- Mark Present or Absent
- Department-wise attendance filtering
- Search student by roll number
- Attendance chart
- Download attendance report
- Print attendance report
- Local storage support

## Departments

- CSE
- IT
- ECE
- EEE
- Mechanical
- Civil

## Technologies Used

- HTML
- CSS
- JavaScript
- Chart.js

## How to Run

1. Open the project in Visual Studio Code.
2. Open index.html using Live Server.
3. The project will open in the browser.
4. Enter student details and mark attendance.
